# ByteSpace New

ByteSpace New is a multi-page frontend application built with **Next.js 15**, **React 19**, **TypeScript**, and **CSS Modules**. It recreates a modern online learning platform with responsive layouts, reusable components, and a clean, intuitive user interface.

## Live Demo

https://bytespace-new-azmari.vercel.app/

---

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** Vanilla CSS & CSS Modules

---

## Implemented Pages

| Page | Route | Description |
|------|-------|-------------|
| **Home** | `/` | Landing page with the hero section, featured courses, categories, and testimonials. |
| **Course Search** | `/search` | Search and browse courses using category filters. |
| **Course Details** | `/course-details` | Course overview, preview, learning outcomes, and enrollment section. |
| **Course Lessons** | `/course-lessons` | Curriculum with lesson and module breakdown. |
| **Course Reviews** | `/course-reviews` | Student ratings and reviews. |
| **Creator Profile** | `/creator-profile` | Instructor profile, statistics, and published courses. |
| **Login** | `/login` | User sign-in interface. |
| **Register** | `/register` | User registration interface. |
| **Custom 404** | `/404` | Custom not-found page. |

## Getting Started

### Clone the repository

```bash
git clone https://github.com/AzmariSultana/ByteSpace-New.git
cd ByteSpace-New
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.
